Student Feedback Sentiment Analysis

This project helps analyze student feedback using AI-driven sentiment analysis, providing valuable insights for teachers.

📌 Project Overview

This system analyzes student feedback using deep learning models (BiLSTM, CNN, and CNN-LSTM) to predict emotions and provide suggestions for teachers.

🛠 Implementation

The project is built using Flask, TensorFlow, and NLP techniques, with a simple web interface to collect feedback and display results from three different models.

📊 Sentiment Analysis

The system categorizes feedback into emotions like joy, sadness, frustration, or confidence, offering personalized recommendations for improving teaching.

🚀 Implementation Process

📄 Step 1: Data Collection

Student feedback is collected and preprocessed using NLP techniques such as tokenization, stemming, and stopword removal.

🤖 Step 2: Model Training

We train three deep learning models (BiLSTM, CNN, CNN-LSTM) using labeled datasets to classify sentiments accurately.

🔎 Step 3: Prediction

User feedback is analyzed by all three models, and the sentiment category (e.g., motivated, struggling) is predicted.

💡 Step 4: Recommendation

Based on sentiment analysis, the system suggests tailored improvements for teaching and student engagement.

🔥 Key Features

💬 AI-Powered Sentiment Analysis

Uses deep learning to classify student feedback into different emotions.

📊 Multi-Model Prediction

Displays results from three models (BiLSTM, CNN, CNN-LSTM) for comparison.

📈 Teacher Recommendations

Provides actionable insights to help teachers improve classroom engagement.
